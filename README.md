AI Dictionary
A beginner-friendly, plain-language reference that explains 69 essential AI terms through simple definitions, everyday analogies, and concrete examples. A single threaded case study at the end shows how all the concepts fit together in a real project.
Overview
AI jargon can be intimidating. This project turns 69 common terms into something anyone can understand. Each term follows the same three-part format — definition, analogy, and example — with a misconception noted where it helps. The dictionary is grouped into 7 categories and sorted for quick lookup, and it ends with a comprehensive example ("Campus Q&A Assistant") that uses 44 of the terms in one continuous story.
Features
- 69 terms across 7 categories — from core concepts to ethics and safety
- Consistent format — definition + real-life analogy + example (+ misconception when useful)
- Beginner-first language — no assumed background, no jargon piling
- Sorted for lookup — by pinyin or English initial within each category
- One threaded case study — see how terms connect in an actual project
- Bilingual — full guides available in both English and Chines
